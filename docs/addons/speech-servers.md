# Piper and Whisper servers

Run Piper (text-to-speech) and faster-whisper (speech-to-text) as Wyoming services and add them to your Home Assistant Assist pipeline. Miku then uses them through the Home Assistant add-on. A browser-side Piper WASM voice is a roadmap item.
