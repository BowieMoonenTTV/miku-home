# Support the project

Miku Home is free and open source, and it stays that way. This page follows the same approach as [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader): optional donations that only cover real costs.

- No paid tiers, no perks, no early access, no ads and no nag screens. Everyone gets the same app.
- The app never asks for money and never contacts a payment site.
- Donations, if they are ever set up, pay only for the costs listed in [docs/costs.md](docs/costs.md).

**Status: no donation link is active yet.** When one exists it will be listed here and in `.github/FUNDING.yml`.

Other ways to help: report accessibility problems, test with your screen reader, translate, or improve docs.
