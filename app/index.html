Captions

Every spoken reply is written here. Shortcut: Alt+Shift+L.

    Avatar

    Miku's avatar is a visual extra. It shows a simple animated face whose mouth moves while Miku talks. It adds no information beyond the captions.

    Keyboard shortcuts
    • Alt+Shift+S: start or stop listening
    • Alt+Shift+T: go to the typing box
    • Alt+Shift+L: go to the captions
    • Alt+Shift+R: repeat the last reply
    • Escape: stop listening and stop speaking
    Home Assistant (optional add-on)

    Only used when your own Home Assistant address is set in config.js. The token stays in this browser on this device.

    Error log (stays on this device)

    Errors are recorded only on this device and never sent. To report a problem, copy or save this log and attach it to a GitHub issue yourself. It never contains audio, what you said, or what you typed.

    Privacy: no accounts, no tracking, no ads. Speech recognition and Miku's voice run on this device. Nothing you say or type leaves this device, except to your own Home Assistant or Ollama server if you set one up. Read the privacy notice.
