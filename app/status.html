Downloads

All downloads are free. Links open the file on GitHub.

  • Android app (APK, 47 MB). Status: signed, built outside CI and uploaded by hand. Not yet tested on a real phone or with TalkBack.
  • Linux Flatpak (43 MB). Status: built outside CI and uploaded by hand. Not yet tested on a real desktop or with Orca.
  • Debian and Ubuntu package (.deb, 45 MB). Status: built outside CI and uploaded by hand. The window opened on the build machine; not yet tested with Orca.
  • Linux AppImage (124 MB). Status: unsigned, not built by CI from the v0.1.0-beta tag (built by a manual CI run from main), untested.
  • Windows installer (45 MB). Status: unsigned, not built by CI from the v0.1.0-beta tag (built by a manual CI run from main), untested. Windows will show a warning.
  • macOS disk image for Intel and Apple silicon (91 MB). Status: unsigned, not built by CI from the v0.1.0-beta tag (built by a manual CI run from main), untested. macOS will show a warning.
  • SHA256SUMS checksum list, to check that a download is complete and unchanged.

No download is needed to use Miku Home in a browser: open the web app.

Testing

  • Web app: passes all automated accessibility and privacy checks, with 0 axe accessibility violations and zero requests to any outside server. Automated checks cannot prove accessibility.
  • Pending: a full walkthrough with the Orca screen reader.
  • Debian and Ubuntu package: the app window opened on the build machine. Not yet tested with Orca.
  • Not yet tested on real devices: Android with the TalkBack screen reader, the Flatpak, Windows, macOS and the AppImage.
