# Code of Conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and remember that accessibility is a core value here. Mocking disability, speech or assistive technology use is harassment.

Report problems privately to the maintainer through GitHub (see SECURITY.md for private reporting). Reports are kept confidential.
